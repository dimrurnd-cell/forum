# Как перенести дизайн в Tilda

FTP не нужен. Вся страница собрана из блоков **T1370 «HTML-код»** — по одному
на шапку, тело страницы и подвал. Значит, перенос — это три вставки кода
в редакторе Tilda.

Проект: **27715696**

|--------------------------|-----------------------|-------------|-------------------|

## Шаг 1. Загрузите фото спикеров

В коде фотографии указаны относительными путями вида
`images/spk/Gelevey.jpg` — на Tilda такого пути нет, поэтому их нужно
заменить на реальные адреса. Файлы лежат в `images/spk/` этого
репозитория: 7 штук, 720×720, суммарно 392 КБ.

**Вариант А — на свой сайт (проще всего).** Загрузите все 7 файлов
в медиатеку donexpocentre.ru, туда же, где лежат остальные картинки
проекта (`/media/filer_public/GG/`). Тогда достаточно одной замены
по всему коду:

```
images/spk/   →   https://www.donexpocentre.ru/media/filer_public/GG/spk/
```

**Вариант Б — на файлы Tilda.** Tilda выдаёт каждому файлу собственный
адрес, общего префикса не будет, поэтому заменять придётся все 7 путей
по отдельности. Чтобы получить адреса: добавьте на любую служебную
страницу блок «Галерея», загрузите в него 7 фото, опубликуйте страницу,
скопируйте ссылки `https://static.tildacdn.com/...` из кода страницы,
затем блок удалите.

Замену делайте в текстовом редакторе **до** вставки кода в Tilda.

## Шаг 2. Вставьте три блока

Для каждой строки таблицы выше:

1. Откройте страницу в редакторе Tilda.
2. Найдите блок «HTML-код» (T1370) — он там единственный.
3. Нажмите «Контент», выделите всё содержимое поля и удалите.
4. Вставьте содержимое соответствующего файла целиком.
5. Сохраните и опубликуйте страницу.

Порядок не важен, но удобнее начать с шапки и подвала — они короткие.

## Шаг 3. Проверьте

- Шапка и подвал подключаются к основной странице через настройки
  проекта, менять там ничего не нужно.
- Виджет TimePad, счётчик Яндекс.Метрики и все цели (`book_click_header`,
  `book_click_hero`, `book_click_countdown`) уже внутри кода — отдельно
  подключать не надо.
- Шрифты (Unbounded, Onest, IBM Plex Mono) подгружаются с Google Fonts,
  ссылки уже прописаны в каждом блоке.
- Логотип и силуэт домов берутся с donexpocentre.ru по прежним адресам.

## Если правите дальше

Файлы в этой папке генерируются из тех же исходников, что и статический
экспорт в корне репозитория. Правьте что-то одно и переносите изменения,
чтобы версии не разошлись.
